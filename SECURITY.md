# Security

If you think you've found a security problem in Pantheon (the web app, the Mac app, the command-line tool, the MCP server or the API), please tell us privately at **[security@pantheon.run](mailto:security@pantheon.run)**. **Don't open a public issue or discussion for it.**

Our disclosure policy, what to include and what we commit to: https://docs.pantheon.run/security

Our security overview: https://pantheon.run/policy/security

Please don't include other people's data, and don't access, change or delete data that isn't yours while testing.
