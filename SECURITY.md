# Security

If you think you've found a security problem in Pantheon (the web app, the Mac app, the command-line tool, the MCP server or the API), please tell us privately. **Don't open a public issue or discussion for it.**

How to reach us, and what we commit to, is on our security page: https://pantheon.run/policy/security

When you write, it helps to include:

- what you found and where (the app, page or address),
- the steps to reproduce it,
- what someone could do with it.

Please don't include other people's data, and don't access, change or delete data that isn't yours while testing.
